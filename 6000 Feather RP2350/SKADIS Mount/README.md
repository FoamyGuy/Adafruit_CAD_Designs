# Feather SKADIS Mount

Hangs the [Adafruit Feather RP2350](https://www.adafruit.com/product/6000) edge-on from an IKEA SKADIS pegboard, so a panel holds many more boards than when they lie flat. The board screws to two M2 heat set inserts in the mount.

![Turntable render](<6000 Feather SKADIS Mount.gif>)

Fits: Standard Feathers with the 0.9 inch hole spacing on the short edge, such as the Feather RP2350, nRF52840 Express and STM32F405 Express. 6000 is the closest PID, since the mount fits most Feathers.

Mounted edge: The short edge opposite USB, so USB points away from the panel.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
