# Metro ESP32-P4 Touch Display 2 Adapter

A printed frame that holds an [Adafruit Metro ESP32-P4](https://www.adafruit.com/product/6536) on the back of a [Raspberry Pi Touch Display 2, 7"](https://www.adafruit.com/product/6079). The frame screws into the display's four Pi bosses, and the Metro screws into four M2.5 heat set inserts in the frame.

![Turntable render](<6536 Metro ESP32-P4 Touch Display 2 Adapter.gif>)

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD |

## Print

Print it flat with the bosses up. It needs no supports. The part is 58.8 x 67.7 x 9.0 mm.

## Hardware

| Part | Qty | Where |
|---|---|---|
| M2.5 heat set insert, 3.5 mm hole x 4.0 mm long | 4 | Metro bosses, pressed in from the top |
| M2.5 x 5 pan head screw | 4 | Metro to the inserts |
| M2.5 x 6 pan head screw | 4 | Frame to the display's Pi bosses |

Screw the frame to the display first, because those screw heads end up under the Metro.

More photos and a video are at [mikeysklar.github.io/touch2-metro-p4-adapter](https://mikeysklar.github.io/touch2-metro-p4-adapter/).
