# Metro ESP32-P4 SKADIS Mount

Hangs the [Adafruit Metro ESP32-P4](https://www.adafruit.com/product/6536) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against a model built from the Adafruit board files.

![Turntable render](<6536 Metro ESP32-P4 SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB-C and the DC jack, so both point away from the panel.

The USB-A port is on the mounted edge and faces the panel, so it can't be used while mounted.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
