# Metro ESP32-S3 SKADIS Mount

Hangs the [Adafruit Metro ESP32-S3](https://www.adafruit.com/product/5500) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit Eagle board.

![Turntable render](<5500 Metro ESP32-S3 SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB-C and the DC jack, so both point away from the panel.

The render uses stand-in parts placed from the Eagle board, since there is no 3D model.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
