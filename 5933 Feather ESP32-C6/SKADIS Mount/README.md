# Feather ESP32-C6 SKADIS Mount

Hangs the [Adafruit ESP32-C6 Feather](https://www.adafruit.com/product/5933) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit Eagle board.

![Turntable render](<5933 Feather ESP32-C6 SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB, so USB points away from the panel.

The holes on this edge are 2.2 mm and 19.11 mm apart, unlike a standard Feather. The arms are shortened to clear the header pads. The render uses stand-in parts placed from the Eagle board, since there is no 3D model.
