# Pico W SKADIS Mount

Hangs the [Raspberry Pi Pico W](https://www.adafruit.com/product/5526) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Raspberry Pi STEP model.

![Turntable render](<5526 Pico W SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB, so USB points away from the panel.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|
| M2 heat set insert, for a 3.3 mm hole up to 3.3 mm deep | 2 |
| M2 x 4 screw | 2 |
