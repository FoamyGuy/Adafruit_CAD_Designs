# Feather ESP32-S3 TFT SKADIS Mount

Hangs the [Adafruit ESP32-S3 TFT Feather](https://www.adafruit.com/product/5483) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<5483 Feather ESP32-S3 TFT SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB-C, with the TFT facing out.

The holes on this edge are 2.2 mm and 19.11 mm apart, unlike a standard Feather, and the arm has a pocket for the module on the underside.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
