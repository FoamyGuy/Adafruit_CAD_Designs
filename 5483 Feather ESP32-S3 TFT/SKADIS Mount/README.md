# Feather ESP32-S3 TFT SKADIS Mount

Hangs the [Adafruit ESP32-S3 TFT Feather](https://www.adafruit.com/product/5483) edge-on from an IKEA SKADIS pegboard, so a panel holds many more boards than when they lie flat. The board screws to two M2 heat set inserts in the mount.

![Turntable render](<5483 Feather ESP32-S3 TFT SKADIS Mount.gif>)

Fits: The ESP32-S3 TFT Feather only. Its holes are smaller and closer to the corners than a standard Feather, and the arm has a pocket for the module on the underside.

Mounted edge: The short edge opposite USB-C, with the TFT facing out.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
