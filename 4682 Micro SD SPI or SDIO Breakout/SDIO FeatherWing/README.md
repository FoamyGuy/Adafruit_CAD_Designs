# Micro SD Breakout SDIO FeatherWing

A FeatherWing that holds an [Adafruit Micro SD SPI or SDIO Card Breakout](https://www.adafruit.com/product/4682) and wires its 4-bit SDIO bus to the Feather, so you can test SDIO without a breadboard.

![Turntable render](<4682 Micro SD Breakout SDIO FeatherWing.gif>)

## Files

| File | What |
|---|---|
| `.step` | Board with headers, for any CAD tool |
| `.3mf` | Board mesh, for test fits |
| `feather-sdio.kicad_pro`, `.kicad_sch`, `.kicad_pcb` | KiCad source |

## Parts

| Part | Qty |
|---|---|
| 1x16 and 1x12 male headers | 1 each |
| 1x09 female socket, SMD | 1 |

Source: [mikeysklar/feather-sdio](https://github.com/mikeysklar/feather-sdio)
