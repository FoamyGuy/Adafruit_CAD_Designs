# Feather STM32F405 Express SKADIS Mount

Hangs the [Adafruit Feather STM32F405 Express](https://www.adafruit.com/product/4382) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit Eagle board.

![Turntable render](<4382 Feather STM32F405 Express SKADIS Mount.gif>)

Mounted edge: The short edge opposite USB, so USB points away from the panel.

The render uses stand-in parts placed from the Eagle board, since there is no 3D model.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|
