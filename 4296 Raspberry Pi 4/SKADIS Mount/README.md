# Raspberry Pi 4 SKADIS Mount

Hangs the [Raspberry Pi 4 Model B](https://www.adafruit.com/product/4296) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Raspberry Pi mechanical drawing and a community STEP model.

![Turntable render](<4296 Raspberry Pi 4 SKADIS Mount.gif>)

Mounted edge: The microSD short edge. USB-C, GPIO, USB, Ethernet and HDMI stay reachable. The microSD card faces the panel.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |
